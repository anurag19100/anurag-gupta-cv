# anurag-gupta-cv

Document store for Anurag Gupta's CV and related certificates. It contains PDF and DOCX-derived files only:
no code, no build, no tests.

## Layout

| Path | What |
|---|---|
| `anurag_gupta_cv.pdf` | CV (PDF) |
| `anurag_gupta_cv_.pdf` | Second CV PDF with a trailing underscore in the name |
| `WebpeInternship/` | Internship certificate and signed letter of recommendation (PDF) |

## Use

Open or download the PDFs. To update the CV, replace the PDF in a branch and open a pull request against
`main`. The source documents the PDFs were exported from are not in this repo.

The files contain personal information (contact details, a signed letter of recommendation).
